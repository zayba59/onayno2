# onayno2

A lightweight static project. The site entry point is `index.html`.

## Local preview

Serve the repository root with any static web server, then open `index.html` through that server.

## Deployment checklist

- Confirm the expected production URL in the hosting provider.
- Publish the repository root as the static site directory.
- Verify the deployed page and browser console after each release.

This README documents the repository structure; deployment credentials and provider settings must remain in the hosting platform.
